# Padmalakshmi G — Developer Portfolio

A responsive personal portfolio website built with HTML5, CSS3, and JavaScript, showcasing projects, education, skills, a downloadable resume, and an interactive contact form.

## Features

- **Responsive Navigation & Mobile Menu:** Sticky header with smooth scrolling and a collapsible mobile menu.
- **Dark / Light Mode Toggle:** Switch themes dynamically with contrasting light and dark palettes.
- **Projects Showcase:** Cards for **Pramaan** and **EcoStream ML** with GitHub repository and live demo links.
- **Education & Resume Download:** Academic details along with direct PDF resume download support (`resume.pdf`).
- **Contact Section & Validation:** Form field validation and direct links to LinkedIn, GitHub, and Email.

## Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, Media Queries), Vanilla JavaScript
- **Icons:** FontAwesome
- **Version Control & Hosting:** Git, GitHub, GitHub Pages / Netlify
